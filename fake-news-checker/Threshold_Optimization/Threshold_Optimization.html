1. Mục tiêu¶

Notebook này thực hiện quy trình Data-Driven Optimization nhằm xác định ngưỡng điểm số (Threshold) tối ưu nhất để phân loại tin thật/giả.

Quy trình thực hiện:

  1. Data Loading: Tải tập dữ liệu database.xlsx.
  2. Batch Inference: Chạy hệ thống Fact-Check trên từng mẫu tin (Search 15 nguồn -> Phân tích -> Tính điểm).
  3. Visualization: Vẽ biểu đồ phân bố điểm số giữa Tin thật và Tin giả.
  4. Grid Search: Tìm ngưỡng cắt (Threshold) để tối đa hóa F1-Score.
  5. Evaluation: Đánh giá hiệu suất mô hình và xuất cấu hình.

3. Thực thi Kiểm chứng (Batch Inference)¶

Hệ thống sẽ chạy qua từng claim, thực hiện quy trình:

  1. Google Search: Lấy 15 snippets.
  2. Stance Analysis: Gửi 1 Request duy nhất (Batch 15) lên LLM.
  3. Scoring: Tính toán điểm số tin cậy (System Score).

Lưu ý: Kết quả được lưu tự động (Auto-save) sau mỗi 5 câu để đảm bảo an toàn dữ liệu.

pbar = tqdm(total=len(df), desc="🔍 Analyzing Claims")
processed_count = 0

for index, row in df.iterrows():
    claim = row['claims']
    true_label = row['label']
    
    # Update thanh tiến trình nếu đã chạy rồi
    if claim in processed_claims:
        pbar.update(1)
        continue
        
    try:
        # === CORE PIPELINE ===
        # Gọi hàm check_fact với num_sources=15
        start_time = time.time()
        result = checker.check_fact(claim, num_sources=15)
        elapsed = time.time() - start_time
        
        if result['status'] == 'success':
            score = result['final_score']
            verdict = result['verdict']['code']
        else:
            score = 0.0
            verdict = "ERROR"
            
        # Lưu buffer
        new_results.append({
            'claim': claim,
            'true_label': true_label,
            'system_score': score,
            'verdict_code': verdict,
            'processing_time': round(elapsed, 2)
        })
        
        # Auto-Save mỗi 5 câu
        if len(new_results) >= 5:
            pd.DataFrame(new_results).to_csv(OUTPUT_FILE, mode='a', header=not os.path.exists(OUTPUT_FILE), index=False)
            new_results = [] # Clear buffer
            
        pbar.update(1)
        pbar.set_postfix({"Last Score": f"{score:.2f}"})

    except Exception as e:
        print(f"⚠️ Error at index {index}: {e}")

if new_results:

Nhận xét về Phân bố điểm số (Score Distribution)¶

Dựa vào biểu đồ trên, ta có thể quan sát được khả năng phân tách của mô hình:

  1. Sự tách biệt (Separation):
    • Tin giả (Màu đỏ): Có xu hướng tập trung ở vùng điểm âm (thường < 0).
    • Tin thật (Màu xanh): Tập trung ở vùng điểm dương (> 0).
  2. Vùng giao thoa (Overlap Area):
    • Khu vực hai đường này cắt nhau là nơi mô hình "lưỡng lự".
    • Mục tiêu của bước tiếp theo là tìm ra một nhát cắt (Threshold) đi qua vùng giao thoa này sao cho tổng lỗi (Tin thật báo giả + Tin giả báo thật) là thấp nhất.

5. Tìm kiếm Ngưỡng tối ưu (Threshold Optimization)¶

Sử dụng thuật toán Grid Search để quét qua các ngưỡng từ -0.9 đến 0.95. Mục tiêu: Tìm ngưỡng F1-Score cao nhất (cân bằng giữa Precision và Recall).

y_true = clean_df['true_label'].values
y_scores = clean_df['system_score'].values

# 1. Hàm Grid Search
def find_best_threshold_metrics(y_true, scores):
    thresholds = np.arange(-0.9, 0.95, 0.01)
    f1_list = []
    acc_list = []
    
    best_f1 = 0
    best_thresh = 0
    
    for t in thresholds:
        preds = [1 if s >= t else -1 for s in scores]
        f1 = f1_score(y_true, preds, pos_label=1)
        acc = accuracy_score(y_true, preds)
        
        f1_list.append(f1)
        acc_list.append(acc)
        
        if f1 > best_f1:
            best_f1 = f1
            best_thresh = t
            
    return thresholds, f1_list, acc_list, best_thresh, best_f1

thresholds, f1_scores, accuracies, optimal_thresh, max_f1 = find_best_threshold_metrics(y_true, y_scores)

Phân tích Ngưỡng tối ưu (Threshold Analysis)¶

Biểu đồ "Biến thiên hiệu suất" cho thấy mối tương quan giữa Ngưỡng chọn và điểm F1-Score:

  • Đường F1-Score (Màu xanh): Tăng dần và đạt đỉnh tại giá trị tối ưu, sau đó giảm xuống.
  • Kết quả: Thuật toán đã tìm ra ngưỡng Optimal Threshold ≈ 0.03.
  • Ý nghĩa:
    • Thay vì chọn số 0 mặc định, việc nhích ngưỡng lên 0.03 giúp mô hình trở nên "thận trọng" hơn.
    • Nó yêu cầu bằng chứng phải đủ mạnh (điểm dương thực sự) mới kết luận là Tin thật, giúp giảm thiểu rủi ro bỏ lọt Tin giả.

⚙️ Cấu hình cho Production¶

Dựa trên ngưỡng tối ưu 0.03 và biên độ an toàn (Safety Buffer) ±0.05, chúng ta thiết lập logic 3 vùng cho hệ thống thực tế như sau:

  1. Vùng Tin Giả (Likely False): Điểm số ≤ -0.02
    • Hành động: Cảnh báo người dùng đây là tin giả.
  2. Vùng Tin Thật (Likely True): Điểm số ≥ 0.08
